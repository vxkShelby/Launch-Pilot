Welcome to LaunchPilot

LaunchPilot reads what your installed launchers already know, locally — no accounts, no telemetry, nothing about your library ever leaves this machine.

  • Up to date No update pending.
  • Update available Action needed. Launchers with pending updates open first.
  • Updating… Install is in progress.
  • Unknown This launcher doesn't expose real update info, so LaunchPilot won't guess.
  • Filled dot: that launcher's process is running. Hollow: it is not.

Fields a launcher doesn't provide (size, last played, build) are left out, never guessed. Use Ignore on a pending update to leave it out of the counts and Update all; restore it in Settings. A tray icon, new-update notifications and Start with Windows are also in Settings; all three are off until you turn them on.

Settings

Background

All off by default. Nothing is sent anywhere: notifications are local Windows toasts and these choices are stored on this PC only.

Notifications appear only while the window is hidden or unfocused. With the tray icon off, Start with Windows opens the normal window instead.

Ignored updates

Nothing ignored.

    Keyboard shortcuts

    • Ctrl+F Focus the filter box
    • F5 or Ctrl+R Refresh now
    • Esc Close a dialog, or clear the filter

    Update all?

        LaunchPilot asks each launcher to start the update. What happens next is up to the launcher.
