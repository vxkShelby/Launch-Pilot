# Support

- **Bug or crash?** [Open an issue](https://github.com/vxkShelby/Launch-Pilot/issues/new?template=bug_report.md).
  If the app crashed, attach the relevant line(s) from
  `%APPDATA%\LaunchPilot\crash.log`.
- **Question, idea, or "does it support X launcher"?** Use
  [Discussions](https://github.com/vxkShelby/Launch-Pilot/discussions) —
  issues are for bugs, Discussions is for everything else.

There's no other support channel (no email, no Discord) — everything routes
through this repo so the history stays public and searchable for the next
person with the same question.
